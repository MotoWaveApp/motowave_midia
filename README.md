# Motowave — mídia pública

Artes prontas para publicação do Instagram do Motowave, servidas por link público
(o Instagram e o Canva só buscam arquivos por URL pública). Gerenciado pelo
Estúdio Motowave (`motowave_social/estudio`) — não edite à mão.

- `<AAAA-MM-DD>/` — uma pasta por semana (o domingo que a abre), com as artes JPEG enviadas
  no "Enviar agenda". O nome começa pelo dia e horário da publicação, então a ordem alfabética
  é a da agenda: `2026-09-29_19h00_lembrete-revisao_01-ca47f2.jpg` (slide `01`; o sufixo muda
  quando a arte é refeita). Fica guardado depois de publicado, como banco de imagens; versões
  refeitas ou reagendadas são apagadas.
- `canva/` — PDFs enviados pra abrir como design editável no Canva
